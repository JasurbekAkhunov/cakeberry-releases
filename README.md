# Cakeberry — релизы Android-приложения

Здесь публикуются установочные файлы (APK) приложения пекарни **Cakeberry** (Фергана).
Приложение само проверяет этот репозиторий и предлагает обновиться прямо внутри приложения.

## Как установить вручную
1. Откройте последний релиз в разделе **Releases**.
2. Скачайте файл для своего телефона — почти всегда это `...-arm64-v8a.apk`.
3. Откройте файл и разрешите установку из этого источника, если телефон спросит.

У каждого файла в описании релиза указана контрольная сумма **SHA-256** — приложение сверяет её перед установкой.
